# AGENTS.md — pre-release/

**Pre-v1.0 incubation logs**, grouped per version (e.g. `v0.1/`). This is the long-form narrative of what
happened while a version was being stabilized — decisions taken, debt opened and paid, lessons in flight.

- One subfolder per milestone version. Inside, free-form dated logs.
- These are a **record**, not a plan: plans are RFCs/tasks; settled decisions are ADRs.
- Once a version ships and is superseded, its folder can be archived (kept in git history) to keep the
  working tree focused on the current line — same "distill up, then clean" spirit as `tasks/`.

Durable, reusable lessons from an incubation belong in `research/learnings/`, not buried here.

See [`../../GOVERNANCE.md`](../../GOVERNANCE.md).
